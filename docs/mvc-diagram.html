2. CONTROLLER PROCESA
El Controller recibe el evento, ejecuta hooks y lógica, y consulta o actualiza el Model.

El Model devuelve los datos actualizados — proyectos filtrados, nuevo tema, SEO meta tags.
🔄
4. VIEW RE-RENDERIZA
React re-renderiza la View con el nuevo estado. El usuario ve el resultado actualizado.
